Excel formulas every freelancer should know

Fourteen formulas that cover most freelance admin: adding up invoices and expenses, flagging overdue payments, working out due dates, and looking up client rates. Every formula works in Excel and Google Sheets, except XLOOKUP, which needs Microsoft 365, Excel 2021, or Google Sheets. Copy the examples into your own tracker and change the cell references to match your sheet.

The formulas

1. SUM — add a column of numbers

Syntax: =SUM(B2:B10)

Freelancer example: Column B holds the amounts of this month's invoices. =SUM(B2:B10) adds them all up for the monthly total.

Returns: The total of the numbers in the range.

2. SUMIF — add only the rows that match a condition

Syntax: =SUMIF(C2:C100, "Travel", D2:D100)

Freelancer example: Column C holds expense categories and column D holds amounts. This adds up only the rows where the category is "Travel", so you can see what travel cost you this year.

Returns: The total of the matching rows only.

3. COUNTIF — count the rows that match a condition

Syntax: =COUNTIF(E2:E100, "Overdue")

Freelancer example: Column E holds invoice status ("Paid", "Sent", "Overdue"). This counts how many invoices are currently overdue, so the number on your summary sheet is always up to date.

Returns: The number of matching rows.

4. IF — show one thing or another depending on a test

Syntax: =IF(B2<TODAY(), "Overdue", "Not due")

Freelancer example: Column B holds invoice due dates. If the due date has passed, the cell shows "Overdue"; otherwise it shows "Not due". This is the formula behind an automatic status column.

Returns: The first value when the test is true, the second when it is false.

5. EDATE — a date a number of months away

Syntax: =EDATE(A2, 1)

Freelancer example: Cell A2 holds the start date of a monthly retainer. =EDATE(A2, 1) gives the date the next payment is due, one month later. Use 3 for a quarterly retainer.

Returns: A date, the same day of the month, the given number of months later (or earlier, with a negative number).

6. TODAY — today's date, always current

Syntax: =TODAY()

Freelancer example: =TODAY()-B2, where B2 is an invoice due date, gives the number of days since the due date. Positive means overdue; negative means still time. The result updates itself every day, so you never type a date by hand.

Returns: The current date, with no time attached.

7. XLOOKUP — find a value in another table

Syntax: =XLOOKUP(A2, Clients!A:A, Clients!B:B, "Not found")

Freelancer example: You type a client name in A2. This looks the name up in column A of a Clients sheet and returns that client's hourly rate from column B — or "Not found" if the name is not listed. Needs Microsoft 365, Excel 2021, or Google Sheets.

Returns: The matching value from the return column, or the fallback text when there is no match.

8. VLOOKUP — the older way to find a value

Syntax: =VLOOKUP(A2, Clients!A:B, 2, FALSE)

Freelancer example: Same job as XLOOKUP: look up the client name in A2 in the first column of the Clients table and return the value from column 2, the hourly rate. FALSE means "exact match only" — always use it for lookups like this. Use VLOOKUP when the sheet must work in older versions of Excel.

Returns: The value from the stated column of the first exact match.

9. TEXT — format a number or date as text

Syntax: =TEXT(A2, "mmm d, yyyy")

Freelancer example: Cell A2 holds a due date. This turns it into readable text such as "Nov 16, 2026", which you can join into an invoice line with & — for example ="Due: "&TEXT(A2, "mmm d, yyyy") gives "Due: Nov 16, 2026".

Returns: Text, formatted as the pattern describes.

10. ROUND — round to a set number of decimals

Syntax: =ROUND(B2*0.2, 2)

Freelancer example: Cell B2 holds an invoice subtotal and tax is 20%. This works out the tax and rounds it to two decimals, so the total never shows stray fractions of a cent. Use it on every calculated money figure.

Returns: The number rounded to the stated number of decimal places.

11. AVERAGE — the average of a range

Syntax: =AVERAGE(B2:B13)

Freelancer example: Column B holds twelve monthly income figures. This gives your average monthly income for the year — useful when a client asks what you usually earn, or when you are setting next year's rates.

Returns: The arithmetic mean of the numbers in the range.

12. MAX — the largest value in a range

Syntax: =MAX(B2:B10)

Freelancer example: Column B holds this year's invoice amounts. This finds your single biggest invoice of the year, which is handy for a year-end summary or for checking whether one client dominates your income.

Returns: The largest number in the range.

13. MIN — the smallest value in a range

Syntax: =MIN(B2:B10)

Freelancer example: Column B holds this month's expenses. This finds the smallest expense, which is a quick way to spot whether a tiny recurring charge — a forgotten subscription, say — is still on the list.

Returns: The smallest number in the range.

14. DATEDIF — days between two dates

Syntax: =IF(B2<TODAY(), DATEDIF(B2, TODAY(), "d"), 0)

Freelancer example: Cell B2 holds an invoice due date. DATEDIF with "d" counts whole days between the due date and today — the number of days overdue. The IF wrapper matters: DATEDIF returns an error when the start date is after the end date, so invoices that are not yet due show 0 instead of an error.

Returns: The number of whole days between the two dates (with "d" as the unit).

Three habits that keep a tracker working

  • One row per invoice, one row per expense. Formulas only stay correct when the data is in tidy rows and columns — no totals typed in by hand inside the data.
  • Round every money figure. A ROUND(..., 2) around tax, discounts and totals stops a one-cent drift from turning into a mismatched invoice.
  • Let dates do the work. A status column built from IF and TODAY() is never out of date, because the sheet re-checks the dates every time it opens.
